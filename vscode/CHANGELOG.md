# Changelog

## 0.1.0

- Open a Python or C call map beside the editor with Ctrl+Shift+V.
- Switch between the current file and related files in the workspace folder.
- Jump from map blocks to source lines and refresh after unsaved edits.
- Explore Python classes, inheritance, decorators, and C callback/IRQ functions.
- Keep map layout and notes in VS Code workspace state without creating project files.
